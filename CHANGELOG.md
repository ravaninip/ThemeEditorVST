# Changelog

All notable changes to this project are documented in this file.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added
- Design check in the Layout tab (sizes that almost match, controls too small to grab, overlaps, uneven spacing,
  elements sticking out of their panel, near-misses in alignment) with one-click fixes, and a *Same size* tool.
- Colour harmonies in the palette generator; the readability list shows *good* from 4.5:1.
- The element list of Solomon now has equally sized knobs.
- Layout tab: drag, resize, hide, align and distribute the elements of a plug-in on a canvas with snapping,
  guides, undo/redo and overlap warnings; layout files (format version 1) and plug-in element lists, with JSON
  Schemas and the element list of Solomon.
- Theme Studio: colour editor with live preview of Solomon, palette generator, readability checks, import and
  export of theme files (format version 1), JSON Schema and example themes.
